# 코드 없이 NPC와 맵 이동을 수정하는 방법

보통 수정할 파일은 **이 폴더의 `maps/*.cfg`와 `dialogue/*.txt`뿐**입니다.
`scripts/`를 열거나 프로그래밍을 배울 필요가 없습니다.
Godot에서 프로젝트를 열고 **F5**로 실행하세요.
디버그 조작은 키보드 위쪽의 **일반 숫자키 8(좌표), 9(새로고침)**입니다.
오른쪽 숫자 패드가 아닌, 글자 키 위에 있는 숫자키를 사용하세요.

## 먼저 해 보기

1. WASD 또는 방향키로 이동합니다. 두 방향을 함께 누르면 대각선으로 움직입니다.
2. NPC 가까이에서 NPC를 바라보고 E 또는 Space를 누르면 대화합니다.
3. E/Space를 한 번씩 눌러 다음 문장을 읽고, 마지막 문장에서 한 번 더 누르면 닫힙니다.
4. 시작 마을의 **위쪽 검은 통로**에 닿으면 두 번째 마을로 갑니다.
5. 두 번째 마을 **오른쪽 위 건물의 검은 문**에 닿으면 실내로 들어갑니다.
6. 실내의 아래 검은 출입구로 나옵니다. 두 번째 마을의 아래 통로로 시작 마을에 돌아옵니다.

게임을 켜 둔 상태에서 파일을 수정하고 **저장한 다음 9**를 누르면 반영됩니다.
9는 현재 맵의 NPC, 대화, 초상화, 이동 연결을 다시 읽습니다.
플레이어 위치는 유지합니다. 대화 중 누르면 대화창은 닫힙니다.
8/9는 Godot에서 실행하는 개발용 기능입니다. 일반 release 내보내기에서는 꺼집니다.

## 파일을 고르기

```text
data/
├─ README_KR.md                 ← 이 설명서
├─ maps/
│  ├─ start_map.cfg             ← 시작 마을 NPC와 북쪽 통로
│  ├─ second_map.cfg            ← 두 번째 마을 NPC, 복귀 통로, 건물 문
│  └─ building_01.cfg           ← 건물 안 NPC와 출입구
└─ dialogue/
   ├─ start_npc.txt             ← 테스트 NPC 대사
   ├─ second_npc.txt            ← 마을 소녀 대사
   └─ building_npc.txt          ← 건물 관리인 대사
```

메모장이나 텍스트 편집기로 여세요. **UTF-8**로 저장합니다.
CFG의 `;`로 시작하는 줄은 설명입니다. TXT의 `#`로 시작하는 줄은 설명입니다.
이름과 파일 경로는 `"따옴표"` 안에, 좌표 숫자는 따옴표 없이 적습니다.
`res://`는 “이 프로젝트 폴더 안”이라는 뜻입니다. 경로에는 `/`를 씁니다.

## NPC 이름 바꾸기

예를 들어 `maps/second_map.cfg`에서 아래 한 줄만 수정하세요.

```ini
[npc:second_npc]
name = "철수"
```

`second_npc`는 NPC를 구별하는 ID입니다. 화면 이름은 `name`입니다.
같은 파일 안에서 NPC ID는 겹치면 안 됩니다. 다른 맵의 ID와는 관계없습니다.
다른 설정 줄은 지우지 말고 그대로 두세요.

## NPC 위치 바꾸기

```ini
position_x = 500
position_y = 240
```

좌표는 **그 NPC가 속한 맵 안의 픽셀 위치**입니다.
X는 오른쪽으로, Y는 아래로 갈수록 커집니다. 맵은 640×480픽셀이고 한 타일은 32픽셀입니다.
캐릭터 발 근처의 몸 중심을 기준으로 합니다. 벽 안이나 맵 바깥에는 배치하지 마세요.
잘못된 위치에 둔 NPC는 오류를 알리고 표시하지 않습니다.

숫자를 쉽게 알아내려면:

1. 게임에서 **8**을 눌러 좌표 표시를 켭니다.
2. NPC를 놓고 싶은 곳으로 플레이어를 이동합니다.
3. 화면의 `PLAYER X`, `Y` 숫자를 CFG의 `position_x`, `position_y`에 복사합니다.
4. 파일을 저장하고 **9**를 누릅니다. 다시 8을 누르면 표시를 끕니다.

NPC 위에는 NPC ID와 현재 좌표가 표시됩니다.
시작 마을의 `(400, 300)`과 실내의 `(400, 300)`은 각각 독립된 위치입니다.

## 대사 바꾸기

CFG에 지정된 `dialogue` 파일을 엽니다.

```ini
dialogue = "res://data/dialogue/second_npc.txt"
```

TXT에는 다음처럼 적습니다.

```text
# 이 줄은 게임에 표시되지 않습니다.
안녕.
오늘 날씨 좋네.

# 빈 줄도 표시하지 않습니다.
저쪽 건물에는 가 봤어?
```

**한 줄 = 대화창 한 페이지**입니다. 빈 줄과 `#` 주석은 건너뜁니다.
긴 문장은 화면 폭에 맞춰 자동으로 줄바꿈하므로 직접 줄을 나누지 않아도 됩니다.
단, 매우 긴 문장은 한 페이지의 높이를 넘길 수 있으니 적당한 길이로 나누세요.
저장하고 9를 누른 뒤 다시 대화하면 처음 문장부터 새 내용이 나옵니다.

## 초상화 바꾸기

1. 준비한 PNG/JPG/WebP/SVG 이미지를 프로젝트의 `assets/portraits/` 폴더에 넣습니다.
2. CFG의 `portrait` 줄을 바꿉니다.

```ini
portrait = "res://assets/portraits/내캐릭터.png"
```

저장하고 9를 누르면 새로운 이미지도 바로 읽습니다. 사진 비율은 유지합니다.
예제 초상화는 96×112 크기이며 세 NPC가 서로 다른 그림을 사용합니다.
파일이 없거나 읽지 못하면 기본 초상화로 대신 표시하고 오류를 알립니다.

## 새 NPC 추가하기

해당 맵의 CFG 맨 아래에 기존 `[npc:...]` 부분을 복사해서 붙이고 ID를 바꿉니다.

```ini
[npc:new_npc]
name = "새 NPC"
position_x = 368
position_y = 280
portrait = "res://assets/portraits/caretaker.svg"
dialogue = "res://data/dialogue/new_npc.txt"
```

`data/dialogue/new_npc.txt` 파일을 만들고 대사를 적습니다.
저장하고 9를 누르면 공통 NPC 씬으로 새 NPC가 생성됩니다.
NPC 전용 씬이나 스크립트를 만들 필요가 없습니다.
NPC를 없애려면 해당 `[npc:...]`부터 다음 `[섹션]` 앞까지의 설정을 지웁니다.
서로 같은 자리에 놓으면 겹치므로 8로 위치를 확인하세요.

## 맵 이동 목적지 바꾸기

출발 맵 CFG에서 해당 통로 설정을 바꿉니다.

```ini
[transition:north_exit]
target_map = "second_map"
target_spawn = "south_entrance"
```

`north_exit`는 출발 맵에 배치한 이동 영역 ID입니다.
`target_map`은 도착 맵의 ID이자 CFG 파일 이름(확장자 제외)입니다.
`target_spawn`은 도착 맵 안의 출현 지점 ID입니다. 숫자 좌표가 아닙니다.

| 맵 ID | 사용할 수 있는 출현 지점 |
|---|---|
| `start_map` | `start`, `north_entrance` |
| `second_map` | `south_entrance`, `building_entrance` |
| `building_01` | `entrance` |

이미 존재하는 통로의 연결 변경은 CFG만 수정하고 9를 누르면 됩니다.
문에서 나온 직후 곧바로 다시 들어가지 않도록 출현 지점은 이동 영역 밖에 배치했습니다.

## 새 출현 지점이나 이동 영역 만들기 (Godot 에디터)

**이 부분만 맵 배치를 위해 에디터를 사용합니다. 코드는 수정하지 않습니다.**

- 출현 위치를 바꾸려면 `maps/도착맵.tscn`을 열고 `SpawnPoints` 아래 Marker2D를 드래그합니다.
- 새 출현 지점은 기존 Marker2D를 복제하고 Inspector의 `Spawn Id`를 고유한 값으로 바꿉니다.
- `Facing`은 출현 후 바라보는 방향입니다. 아래 `(0, 1)`, 위 `(0, -1)`입니다.
- 새 이동 영역은 `Transitions` 아래 기존 영역을 복제합니다. Inspector의 `Transition Id`를 바꿉니다.
- 위치는 드래그하고 크기는 `Area Size`에서 바꿉니다. CollisionShape2D를 따로 수정할 필요가 없습니다.
- CFG에 같은 ID의 `[transition:새ID]`를 추가하고 `target_map`, `target_spawn`을 적습니다.
- 씬 배치를 수정했으면 씬을 저장하고 게임을 다시 실행합니다. 9는 씬 배치를 다시 읽지 않습니다.

완전히 새 맵을 만들 때는 기존 맵 씬과 CFG를 복제하세요. CFG의 `[map]`에 다음을 설정합니다.

```ini
[map]
id = "new_map"
title = "새 마을"
scene = "res://maps/new_map.tscn"
default_spawn = "entrance"
```

파일 이름도 `new_map.cfg`로 맞추고, 씬의 SpawnPoints에 `entrance`를 만드세요.
ID에는 영문, 숫자, `_`만 씁니다. 화면 이름과 대사는 한글을 자유롭게 쓸 수 있습니다.
현재 맵 지형은 세 종류의 단순한 placeholder입니다. 신규 지형 제작은 별도의 작업입니다.

## 파일을 잘못 썼을 때

오류가 생기면 상단에 알림이 나옵니다. **8**을 누르면 최근 오류 내용이 보입니다.
Godot 아래쪽 **출력(Output)** 창에는 전체 오류가 남습니다.

```text
[CONTENT ERROR]
File: 오류가 난 파일 경로
Section: 오류가 난 NPC 또는 이동 영역 ID
Problem: 어떤 값이 잘못됐는지 설명
Current value: 현재 잘못된 값
```

- `position_x = "hello"`: 좌표는 따옴표 없는 숫자로 고치세요.
- 대화 파일이 없음/비어 있음: 안내 문장으로 대신 표시합니다. TXT 경로와 내용을 확인하세요.
- 초상화가 없음: 기본 초상화로 표시합니다. 이미지 경로를 확인하세요.
- 맵 또는 출현 ID가 없음: 해당 이동 연결을 끕니다. 위 표나 에디터를 확인하세요.
- NPC/이동 영역/출현 ID 중복: ID가 서로 겹치지 않게 바꾸세요.
- 따옴표나 대괄호를 빠뜨림: 파일 전체를 읽지 못합니다. 새로고침 시 기존 콘텐츠를 유지합니다.
- 맵의 `id`, `scene` 변경: 게임을 다시 실행해야 합니다.

수정 후 저장하고 9를 누르세요. 정상이라면 오류 알림이 사라집니다.
출현 지점은 벽과 이동 영역 밖에 두세요. 출현 위치가 막힌 곳이면 에디터에서 옮겨야 합니다.
맵 이동 때는 다른 맵의 연결과 데이터도 확인하므로, 오류 File 경로를 보고 해당 파일을 고치세요.

## 내보내기 참고

현재 검증은 Godot 에디터/개발 실행 기준입니다. 다른 PC로 내보낼 때 Export의
비리소스 파일 포함 필터에 `data/**/*.cfg, data/**/*.txt`를 추가해야 합니다.
한글이 표시되는 시스템 폰트가 없는 PC에는 사용할 권한이 있는 한글 폰트도 포함해야 합니다.
